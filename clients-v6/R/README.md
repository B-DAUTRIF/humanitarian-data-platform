# HDPClientsR 6.0.0

Install from the package directory with `R CMD INSTALL .` or `remotes::install_local('.')`.

Use `hdp_sources()`, `hdp_operations()`, `hdp_preview()` and `hdp_request()`. The same compressed inventory catalog used by the Python package drives endpoint and parameter serialization. Write/administration operations require `allow_unsafe=TRUE` explicitly.
