Accès opérateur HDP

Les fonctions privées sont protégées par une passkey ou une clé de sécurité. La vérification utilisateur est obligatoire.

Ce navigateur ne fournit pas WebAuthn. Utilisez un navigateur récent sur l’origine configurée en HTTPS, ou sur localhost.
Premier accès : saisissez une seule fois le secret d’installation présent dans le fichier .env. Il ne sera ni placé dans l’URL ni stocké par le navigateur.
