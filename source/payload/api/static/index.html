Ces garde-fous sont appliqués aux recherches manuelles et planifiées.

Les scripts sont stockés dans le projet mais leur exécution reste désactivée. Cela évite qu’une planification exécute du code non vérifié.

Dépôt GitHub du projet

Préparez puis créez un dépôt distinct. La visibilité privée reste la valeur recommandée.

Le jeton GitHub est global, lu depuis .env, jamais renvoyé par l’API ni stocké dans le projet. La création initialise seulement le dépôt ; elle ne publie pas les données locales.

Géodonnées officielles ONU / HDX

Choisissez les téléchargements automatiques puis un pays ou une zone présent à la fois dans ONU M49 et dans chaque catalogue HDX COD sélectionné.

La liste géographique est calculée sur les identifiants ISO3/M49 des groupes HDX canoniques. COD‑AB accepte les niveaux cod-enhanced ou cod-standard. Une combinaison n’est téléchargée que si toutes ses familles restent disponibles.
