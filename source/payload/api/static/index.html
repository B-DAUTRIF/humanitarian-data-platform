Un espace local pour trouver, comprendre et traiter les données humanitaires

Humanitarian Data Platform (HDP) réunit dans une même application la recherche sur plusieurs sources publiques, le téléchargement contrôlé, la bibliothèque de fichiers et les traitements reproductibles. Elle est conçue en priorité pour les données de santé publique, d’épidémiologie et de réponse humanitaire, tout en conservant la provenance et l’intégrité de chaque ressource.

Les données restent organisées par projet sur votre poste. Vous pouvez comparer des catalogues en parallèle, importer vos propres données, scripts et documents, cartographier les fichiers géographiques, planifier les mises à jour et interroger les vues SQL du projet en lecture seule.

Recherche HDX Data Grid

Recherche pilotée par périmètre, localisation, période, format et dimensions de couverture. HDP conserve les descriptions, schémas, dates, périodicités et indicateurs de fiabilité.

HDP distingue explicitement l’appartenance publiée par HDX d’une classification candidate calculée localement.

Préférences du projet

Ces garde-fous sont appliqués aux recherches manuelles et planifiées.

Les limites de téléchargement restent indépendantes des limites d’exécution des traitements.

Exécution contrôlée Python / R

Les traitements s’exécutent dans un conteneur non privilégié, sans réseau, sans socket Docker et sans Shell.

Le réseau est techniquement coupé par network_mode: none. Les allowlists ne sont pas simulées : elles restent indisponibles tant qu’un proxy d’egress dédié n’est pas intégré.

Dépôt GitHub du projet

Préparez puis créez un dépôt distinct. La visibilité privée reste la valeur recommandée.

Le jeton GitHub est global, lu depuis .env, jamais renvoyé par l’API ni stocké dans le projet. La création initialise seulement le dépôt ; elle ne publie pas les données locales.

Géodonnées officielles ONU / HDX

Choisissez les téléchargements automatiques puis un pays ou une zone présent à la fois dans ONU M49 et dans chaque catalogue HDX COD sélectionné.

La liste géographique est calculée sur les identifiants ISO3/M49 des groupes HDX canoniques. COD‑AB accepte les niveaux cod-enhanced ou cod-standard. Une combinaison n’est téléchargée que si toutes ses familles restent disponibles.

Importer depuis l’ordinateur

Ajoutez un fichier de données, un script ou un document de travail au projet actif.

Formats exécutables refusés. Les noms sont assainis, la taille est bornée et une empreinte SHA-256 est calculée pendant l’import.
