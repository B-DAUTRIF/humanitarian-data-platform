# Limites connues - HDP 4.1.0

- HDP est mono-utilisateur, local et sans authentification réseau.
- Les appels réels dépendent de la disponibilité, des quotas, contrats et
  licences des producteurs ; les tests locaux n'interrogent pas les dix API.
- ReliefWeb et HDX HAPI exigent un identifiant d'application externe.
- Les portails de référence sans contrat public stable ne sont pas scrappés.
- R est optionnel ; les scripts R ne s'exécutent pas si le service n'est pas
  installé.
- L'installateur livré n'est pas signé Authenticode et doit encore faire l'objet
  d'une recette manuelle Windows 10/11 avec Docker Desktop.
- Le catalogue de liens a été vérifié au 15 août 2026 ; une documentation tierce
  peut déplacer une page après cette date.
- Aucune licence HDP explicite n'est ajoutée : le dépôt reste privé.
