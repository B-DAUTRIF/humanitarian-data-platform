# HDP V6.0.0 — Changelog consolidé

La V6 conserve les acquis fonctionnels des lignes antérieures : installation Windows native et mise à niveau préservant les données, FastAPI/PostgreSQL/PostGIS, module R optionnel, projets et préférences, recherche fédérée, sources humanitaires et sanitaires, COD officiels/M49/HDX, données locales, RSS, carte, scripts et recettes, notebooks, planifications, SQL en lecture contrôlée, synchronisation GitHub et documentation des technologies.

La consolidation V6 ajoute comme exigences de livraison : identité 6.0.0 native dans les sources, inventaire exhaustif accessible dans l'interface principale, documentation générée de chaque paramètre API et blocage CI si la couverture canonique n'est pas respectée.
