# Archives techniques hors distribution

Ce dossier conserve uniquement les fichiers historiques uniques qui ne sont présents dans aucune distribution `dist/<version>/`.

Les scripts ou binaires déjà archivés à l’identique dans `dist/` ne sont pas recopiés ici. Les fichiers sont classés par version sous `source-history/<version>/` et ne doivent plus être utilisés comme source courante.
